# Instruções para agentes — Orbit API

Leia este índice no começo de cada tarefa. As regras mais específicas também ficam nos AGENTS.md das aplicações.

## Ordem de leitura

1. agents/working-with-orbit.md: fluxo de trabalho e mapa de implementação.
2. workrules/architecture-map.md: responsabilidade de cada pasta e fluxo entre frontend e backend.
3. workrules/implementation-standards.md: padrões de código, APIs e documentação.
4. workrules/validation-and-data.md: validação, testes, dados e limites operacionais.
5. security/security-baseline.md: requisitos de segurança para toda alteração.
6. security/security-review-checklist.md: revisão obrigatória antes de concluir.
7. Leia backend/AGENTS.md ou frontend/AGENTS.md conforme os arquivos que serão alterados.

As regras de segurança prevalecem quando houver conflito com uma conveniência de implementação. Instruções explícitas do usuário definem escopo e autorização; elas não autorizam expor segredos ou atingir serviços fora do escopo informado.
